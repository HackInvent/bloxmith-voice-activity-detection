Detect speech, without transcribing

Listening starts at Run. The JSON events report the start and the end of speech; your Python block decides on interruptions.

Wire the microphone to audio_in and its commands to command_in to close every capture cleanly. Use a headset: the VAD does not tell your voice from the speaker.

Settings for the next Run

Apply saves the settings. Stop, then Run, activates them.

{{ settings_html }}

Starting point: requirement 2, 160 ms and −48 dBFS. Requirement 0 / 1 / 2 / 3 asks for a speech score of 0.50 / 0.60 / 0.70 / 0.80. Volume alone never triggers a detection. A sound threshold closer to 0 ignores more faint noises, but can miss a quiet voice. The silence delay is not an end-of-sentence detection.

Requirements and diagnostics

FFmpeg, NumPy and ONNX Runtime are required. The verified Silero model ships with the block. The events report the speech score and the sound level; no audio is recorded or sent by this block.
