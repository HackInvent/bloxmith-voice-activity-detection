Détecter la parole, sans transcrire

L’écoute commence au Run. Les événements JSON signalent le début et la fin de parole ; votre bloc Python décide des interruptions.

Reliez le micro à audio_in et ses commandes à command_in pour terminer proprement chaque capture. Utilisez un casque : le VAD ne distingue pas votre voix du haut-parleur.

Réglages du prochain Run

Appliquer enregistre les réglages. Stop puis Run les active.

{{ settings_html }}

Point de départ : exigence 2, 160 ms et −48 dBFS. L’exigence 0 / 1 / 2 / 3 demande un score de parole de 0,50 / 0,60 / 0,70 / 0,80. Le volume seul ne déclenche jamais. Un seuil sonore plus proche de 0 ignore davantage de bruits faibles, mais peut manquer une voix discrète. Le délai de silence n’est pas une détection de fin de phrase.

Prérequis et diagnostic

FFmpeg, NumPy et ONNX Runtime sont nécessaires. Le modèle Silero vérifié est fourni avec le bloc. Les événements indiquent le score de parole et le niveau sonore ; aucun audio n’est enregistré ou envoyé par ce bloc.
